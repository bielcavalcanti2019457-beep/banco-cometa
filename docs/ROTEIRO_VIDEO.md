# Roteiro do vídeo (5 a 10 minutos – todos os integrantes devem falar)

Dica: grave a tela do terminal com o sistema aberto. Use a opção **5** do menu para carregar dados de exemplo antes de demonstrar.

| Tempo | Quem | O que mostrar e falar |
|---|---|---|
| 0:00–0:45 | Integrante 1 | Apresentar o grupo, a disciplina e o projeto: "Banco Cometa, sistema bancário no terminal". Problema: controlar clientes, contas e saldos sem erros. |
| 0:45–1:30 | Integrante 1 | Menu principal: cada opção abre um submenu; 0 volta/sai. Mostrar uma opção inválida (ex.: `abc`) e o erro. |
| 1:30–3:00 | Integrante 2 | **Clientes:** cadastrar (mostrar CPF inválido, CPF repetido e menor de idade sendo recusados), listar, consultar, alterar (ENTER mantém o valor) e excluir. |
| 3:00–4:30 | Integrante 2 | **Contas:** abrir corrente e poupança, tentar abrir duas do mesmo tipo (recusa), alterar limite, tentar encerrar com saldo (recusa). Mostrar que cliente com conta não é excluído. |
| 4:30–6:00 | Integrante 3 | **Operações:** depósito, saque usando o limite, saque acima do disponível (recusa), transferência e extrato. |
| 6:00–7:00 | Integrante 3 | **Relatórios:** saldos do banco, ranking por saldo e movimentações. |
| 7:00–9:00 | Todos (dividir) | **Código:** mostrar os arquivos. `dados.py` = 3 listas de dicionários; `utilidades.py` = validações e `executar_menu`; um módulo por assunto (clientes, contas, transacoes, relatorios); `main.py` só liga os menus. Explicar função, lista, dicionário e como o ID automático funciona. Mostrar `python testes.py` (29 testes OK). |
| 9:00–9:30 | Integrante 1 | Mostrar o repositório no GitHub (branches, commits, Pull Requests) e encerrar. |

Se o grupo tiver menos de 3 integrantes, divida os blocos entre os presentes. O vídeo deve ficar entre 5 e 10 minutos.
